# dsh-session-admin

给 DeepSeek Harness 用的会话树：按工作区分组，可以建文件夹、拖拽摆放、置顶、归档和删除。设置页和侧栏共用同一棵树。

## 功能

- 工作区文件夹、自建文件夹、未归档分组；会话在文件夹之间拖动，文件夹和置顶项也能拖着排序。
- 会话和文件夹都能置顶，置顶的排在最前。
- 行菜单：置顶、重命名、归档 / 取消归档、删除；工具栏有「显示已归档」。
- 多选后批量删除、批量归档 / 取消归档。
- 搜索、排序（默认排序 / 最近更新 / 恢复默认）。
- 侧栏替换：开关打开后，侧栏的工作区区域换成这棵树，工作区标题栏的搜索、排序、添加工作区一并提供；品牌行、新会话按钮和底部保留原生。
- Agent 工具 `session_admin`：`list` 列出会话，`delete` 删除指定 id。

移动和置顶只改显示位置，会话的原生工作区归属不变。

## 安装

需要 DSH 的 `web` profile 和 `0.2.1-rc.5` 或兼容版本。

```bash
dsh plugin --profile web add github:Sunhelter/dsh-session-admin
```

装完重启一次 Harness。卸载：

```bash
dsh plugin --profile web remove @local/dsh-session-admin
```

## 使用

设置 → **会话** 打开树；上方的开关把侧栏那块区域换成同一棵树。

- 拖到文件夹头或行下方空白：追加到该文件夹。
- 拖到某行的上半 / 下半：插在它前面 / 后面。
- 拖文件夹头：调整文件夹顺序，原生侧栏跟着变。
- 置顶区：拖到某一项上调整顺序，最后一项下面的细条拖到末尾。

文件夹的 `...` 可以改名、删除、置顶；工作区文件夹的 `+` 在该工作区新建会话，自建文件夹的 `+` 等同左上角的「新会话」。会话行 `...` 里是置顶、重命名、归档 / 取消归档和删除。

删除不可恢复，正在运行的会话会被跳过；已删除的行要等 Host 重启才会从原生侧栏消失。
