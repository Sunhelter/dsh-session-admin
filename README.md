# dsh-session-admin

给 DeepSeek Harness 用的会话管理：一份平铺的会话卡片列表，按最后活动时间倒序、按天分组，顶部是置顶项。设置页和侧栏共用同一套卡片。

## 功能

- 卡片第一行：左侧一格按「状态点（运行中 / 完成未读）→ 置顶图钉 → 自动化任务时钟」显示其中一个，然后是标题，悬停出现置顶和 `…`；第二行是工作区名和相对时间。
- 按「今天 / 昨天 / 近 7 天 / 近 30 天 / 更早」分组；置顶的会话排在最前，不参与日期分组。
- 行菜单：置顶、重命名、归档 / 取消归档、删除；工具栏有「显示已归档」。
- 多选后批量删除、批量归档 / 取消归档；搜索匹配标题或目录；没有轮次的空会话不显示。
- 例外是当前焦点上的空会话：它作为「新会话」卡片出现，切走即消失。它按时间排进对应的日期分组，不像原生那样固定在列表最前。
- 搜索图标右侧的多选按钮：进入后每张卡片前出现圆形勾选，底部并排「置顶 / 删除」，新会话按钮让位给「选择对话 / 已选择 N 个对话」和关闭按钮；当前会话的卡片有底色。
- 侧栏切换：品牌行右侧（原生收起按钮左边）多一个切换按钮，图标跟着当前侧栏走——原生侧栏是汉堡，点一下换成同一份卡片列表，图标变成工作区文件夹；默认打开的就是我们的列表，标题栏保留搜索和添加工作区（弹出的是原生目录对话框），面板入口只在原生侧栏出现。品牌行、新会话按钮和底部始终是原生。
- Agent 工具 `session_admin`：`list` 列出会话，`delete` 删除指定 id。

置顶只是换显示位置，不会改变会话的原生工作区归属。置顶状态存在浏览器 `localStorage` 里（key `session-admin.pinned`），换浏览器或清站点数据会回到无置顶。

橙点沿用原生的「完成未读」状态：只有会话在后台跑完、之后还没被点开时才置位；状态只存在客户端内存里，刷新页面后会清空。

原生口径里定时任务投递的消息不算用户消息，会话时间不会因此前进，被提醒唤醒过的会话会一路往下掉。这里拿定时任务自己的投递时间兜底，所以这类会话按最近一次投递排序和分组。

## 安装

需要 DSH 的 `web` profile 和 `0.2.1-rc.5` 或兼容版本。

```bash
dsh plugin --profile web add github:Sunhelter/dsh-session-admin
```

装完重启一次 Harness。卸载：

```bash
dsh plugin --profile web remove @local/dsh-session-admin
```

## 使用

设置 → **会话** 打开列表；侧栏顶部的切换按钮在「原生侧栏 / 卡片列表」之间来回切。

- 点卡片打开会话，勾选框用于多选；Tab 聚焦后 Enter / 空格也能打开。
- 悬停卡片出现的图钉按钮或 `…` 菜单里可以置顶 / 取消置顶；置顶项单独成组。
- `…` 菜单还有重命名、归档 / 取消归档和删除。归档时如果会话还在运行，会先问「停止并归档」。
- 删除不可恢复，正在运行的会话会被跳过；目录已经不在的会话也按已删除处理。插件自己的列表会立即去掉这些行并记住，刷新后不会再出现；原生侧栏要等 Host 重启才消失。
